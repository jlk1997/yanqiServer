## 本波交付

1. **匹配一页纸**：为什么对得上、风险提示、权利/TRL、建议下一步（按企业/科研/经纪人微调）。
2. **园区观察深化**：区域热度卡、脱敏案例种子、政策全文可展开、汇报小抄。
3. **五壳微文案 / 空状态 / 移动底栏**：统一 `YB.bindSideNav` 高亮；空状态带下一步。
4. **门禁**：`npm run gate`；波次 `M29-explain-park`；诚实综合约 **93%**。

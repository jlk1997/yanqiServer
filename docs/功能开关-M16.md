# 功能开关 · M16

## 默认值（代码 `flags.defaults.ts`）

| key | 默认 | 说明 |
|-----|------|------|
| board_dnd | 开 | 门户看板拖拽/键盘挪列 |
| pwa | 开 | 门户 SW；关则尝试注销 |
| webhooks | 开 | 出站 Webhook（仍默认干跑） |
| ai_reports | 开 | 分析报告生成 |
| team_invite | 开 | 协作邀请 |
| global_search | 开 | 运维 omnibox（预留） |
| billing_checkout_stub | 开 | 结账桩 |

## 优先级

**租户 `Tenant.features` 覆盖 > 全局 `FeatureFlag` 表 > 代码默认**

## API

- `GET /api/flags?tenantId=default` 解析后列表（公开）
- `GET /api/flags/defaults`
- `POST /api/flags/global` `{ key, enabled, note? }` 超管
- `POST /api/flags/tenant` `{ tenantId, key, enabled }`
- `POST /api/flags/tenant/clear` 去掉租户覆盖

运维台「套餐与开关」可点按钮切换。关 `webhooks` 时 emit 直接跳过；关 `board_dnd` / `ai_reports` / `team_invite` 时对应 API 返回 403。

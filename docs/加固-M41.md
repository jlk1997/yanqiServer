# 研企通 · 加固（M41）

> 大白话：这一波不堆新空功能，专门修洞、提速、把「点了有没有反应」做满。交付心态仍按「做到像 200%」；测量综合约 **99.1%**（可靠性微抬，**不为刷到 100%**）。**支付维仍约 45%**（无真 PSP，从不真扣款）。

## 审计发现（高优先）

| 洞 | 风险 | 本波处理 |
|----|------|----------|
| 园区 JSON 读改写在 `await` 间隙可丢更新 | 审批/案例并发错乱 | `AsyncMutex` 串行化 `seedFromDemands` / `publishDesensitizedCase`；原子 rename 写盘 |
| `GET /billing/checkout/:id` 未鉴权可回 `stubToken` | 伪造 simulate-pay | 未授权脱敏；owner/ops/令牌才给全量 |
| `simulate-pay` / `markPaid` 可双击双开订阅发票 | 账本脏数据 | 乐观 `pending→paid`；订阅/发票幂等 |
| `GET /billing/reconcile` 缺运营校验 | 全局账单泄露 | 仅 ADMIN/OPERATOR/OPS_VIEWER/API-Key |
| `runMatch` 可并发连点 | 重复匹配写库 | 进程内 in-flight 互斥 + 中文 `MATCH_BUSY` |
| 佣金状态可任意跳 | 账本逻辑漏洞 | stub→pending→approved→paid 状态机 |
| 幂等键覆盖不全 | 导入/园区/账单重复提交 | 扩展 Idempotency 路径 |
| 五壳 `YB.api` 无超时、401/403 常静默 | 体验像「卡死」 | 统一 toast / 顶栏等待 / 安全条 / 超时 / 自动幂等键 |
| 工作台首页连点打满库 | 慢 | 4s 私有短缓存 + ETag |
| 长任务无进度口 | 干等 | `GET /api/jobs/progress`；导入按行刷 percent |

## 本波交付

1. **业务逻辑加固**：园区互斥、账单鉴权脱敏、匹配 in-flight、佣金 FSM、幂等扩展  
2. **性能/并发**：工作台 home 短缓存、匹配互斥、导入进度、任务进度 API（仍 Nest+PG，无假微服务）  
3. **UX 反馈**：五壳 + 登录 + ops 路径覆盖等待/成功失败/401·403·429 安全反馈；禁止静默失败  
4. **门禁**：`npm run gate`；波次 `M41-harden-perf-feedback`；`maturityApprox=0.991`

## 刻意没做

真 PSP、政务专网、电子签、运营台微前端、虚报 ≥99.5%。

## M42 建议（给主代理接着循环）

1. **导入/匹配作业可取消 + 前端进度条组件**（接 `jobs/progress` 与 import report.progress）  
2. **客户端 stale 刷新**：关键写操作后自动 `?fresh=1` 打穿 home 缓存  
3. **园区公文板也走 docsMutex**（批量签发与红头 ZIP 并发）  
4. **安全自检补用例**：未登录 checkout 不得回 stubToken；佣金非法跳转 400  
5. 仍等：真人试点 CSV 反馈 / 真收款凭证

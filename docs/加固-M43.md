1. **匹配 in-flight 软取消 + 细粒度进度**
   - `MatchesService.runMatch` 支持 `cancelCheck` / `onProgress`（按需求边界停）
   - `JobsService` 入队匹配时桥接 `liveJobs`：percent / step / batchIndex / batchTotal / bannerZh
   - `GET /api/jobs/progress` 回传 step / phase / batch*
2. **导入取消后差分续跑（skip-done）**
   - 取消时 `report.remainingRows` + `writtenKeys` + `resumeAvailable`
   - `POST /api/imports/enterprise/jobs/:id/resume`（默认异步）
   - 运营台「差分续跑」按钮
3. **五壳写操作统一 bust**
   - `YB.api` 对 POST/PATCH/PUT/DELETE 成功后自动 `bustHomeCache()`（`noBust` / 登录登出 / progress / home/bust 除外）
4. **E2E**：`scripts/smoke.mjs` 异步导入 → 取消 →（若有剩余）差分续跑
5. **门禁**：`npm run gate`；波次 `M43-match-softcancel-import-resume-bust-e2e`；`maturityApprox=0.993`

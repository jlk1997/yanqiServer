## 本波交付

1. **匹配取消 → 按 remainingDemandIds 续跑**
   - `MatchesService` 取消时落 `processedDemandIds` / `remainingDemandIds` / `resumeAvailable`
   - `POST /api/jobs/:id/resume` 只入队未处理需求
   - 运营台「按剩余需求续跑」+ 进度面板续跑按钮
2. **导入冲突合并策略**
   - `fill-empty`（仅补空，默认） / `skip`（跳过已有） / `overwrite`（覆盖已有）
   - `GET /api/imports/enterprise/merge-strategies` + 续跑/导入 body 可带 `mergeStrategy`
   - 中文 label/tip；进度里展示当前策略
3. **进度 SSE**
   - `GET /api/jobs/progress/stream`、`GET /api/imports/enterprise/jobs/:id/progress/stream`
   - 前端 `EventSource` 优先；失败自动强化轮询；保留取消
   - `phaseZh` / `phaseText`（含 batch i/n）
4. **工作台 home 缓存键**
   - `uid::shell::tenantId`；bust 按 uid 前缀清掉全部壳键
5. **门禁**：`npm run gate`；波次 `M44-match-resume-merge-sse-homekey`；`maturityApprox=0.994`

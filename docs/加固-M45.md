> 大白话：取消/部分完成的**匹配与导入**收成一张冷静的「续跑任务卡」；进度 SSE **拒绝匿名**（cookie / Bearer / `?access_token=`）；导入续跑前可看**行级冲突预览**；工作台 home 的 **ETag × shell 缓存键**进门禁。交付心态仍按「做到像 200%」；测量综合约 **99.5%**（本波有实质加固，**不是虚报刷分**）。**支付维仍约 45%**（无真 PSP，从不真扣款）。

## 本波交付

1. **统一续跑任务卡**
   - `GET /api/jobs/resume-cards`
   - 运营台「今天先干什么」区：`#resumeTaskCards`（进度 / 取消 / 续跑 / 导入合并策略）
   - `YB.loadResumeCards` / `YB.renderResumeCards`（五壳可复用）
2. **SSE 鉴权收紧**
   - 流接口二次校验：无 user / API Key / ops cookie → **401** `SSE_AUTH_REQUIRED`
   - 中间件支持 EventSource 用的 `?access_token=` / `?token=`（浏览器不能自定义头）
   - 前端 `sseUrl` / `YB.withSseAuth` 自动拼 token；优先 cookie
3. **导入冲突预览**
   - `GET /api/imports/enterprise/jobs/:id/conflict-preview?mergeStrategy=`
   - 行级中文：将新建 / 将跳过 / 将覆盖 / 将仅补空 / 已写入跳过
   - 运营台「冲突预览」+ 续跑卡内预览
4. **门禁**：匿名 SSE 401；home ETag 与 ops/enterprise **不同 cache-key**；`If-None-Match` 路径；`npm run gate`
5. 波次：`M45-resume-cards-sse-auth-conflict-preview-etag` · `maturityApprox=0.995`

## SSE 威胁模型（简）

| 通道 | 用途 | 风险 | 缓解 |
|------|------|------|------|
| Cookie `yanqi_token` | 浏览器 EventSource + `withCredentials` | CSRF 已有中间件；XSS 可偷 cookie | HttpOnly 化属后续；CSRF lax/strict |
| `Authorization: Bearer` | fetch / 工具 | 正常 | 优先 |
| `?access_token=` | **仅** EventSource 兜底 | 进代理日志 / Referer | 前端仅 SSE 用；文档警告；勿截屏带 token |
| `?apiKey=` / `X-API-Key` | 运营脚本 | 泄露=运营权 | 演示钥；生产换钥+IP allowlist |
| 匿名 | — | **拒绝** | 401 + 中文码 |

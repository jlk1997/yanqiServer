## 本波交付

1. **SSE 一次性短票**
   - `POST /api/jobs/sse-ticket` → `{ ticket, expiresInMs, oneTime: true }`
   - 开流：`?sse_ticket=`（中间件**消费即废**）
   - 前端 `YB.withSseAuth` / ops `sseUrl`：**先 mint 短票**，失败再退 `access_token`
   - 响应头 `X-Yanqi-Sse-Auth: sse-ticket | query-token | session`
2. **壳侧续跑卡**
   - `GET /api/jobs/resume-cards?shell=enterprise|research|ops&kinds=match`
   - 企业/科研：只 `match`，且 demandIds 与本单位需求相交；**不含导入**
   - `work-enterprise.html` / `work-research.html` 首页挂载
   - TENANT_ADMIN / ORG_USER 可对匹配任务 `cancel` / `resume` + 领短票（导入仍仅运营）
3. **冲突预览 CSV**
   - `GET /api/imports/enterprise/jobs/:id/conflict-preview.csv?mergeStrategy=`
   - 运营台「导出预览 CSV」+ 续跑卡内按钮
4. **home 缓存指标**
   - `GET /api/metrics/home-cache`、`GET /api/workbench/home/cache-stats`
   - health 挂 `homeCache`（hits/misses/bypass/notModified/hitRate）
5. 波次：`M46-sse-ticket-shell-resume-conflict-csv-home-metrics` · `maturityApprox=0.996`

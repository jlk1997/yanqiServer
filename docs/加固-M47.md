## 本波交付

1. **SSE 短票 path 绑定**
   - `POST /api/jobs/sse-ticket` body：`{ streamPath, purpose, ttlMs }`
   - 票仓：进程内 Map + `.data/sse-tickets.json`（单机可跨重启短窗口）；`REDIS_URL` 已配时可选同步，未配不硬依赖
   - 开流：`?sse_ticket=`；请求 path ≠ 绑定 path → **401 `SSE_TICKET_PATH_MISMATCH`** 且**不消费**
   - 前端 `YB.withSseAuth` / ops `sseUrl` mint 时带目标 `streamPath`
2. **科研壳续跑反查**
   - `GET /api/jobs/resume-cards?shell=research`
   - 除本单位自有需求外：按 Capability/Outcome → `MatchResult.demandId` 反查，命中过本单位能力/成果的匹配任务也会出现
   - 响应：`researchReverseLookup`、`researchMatchedDemandCount`
3. **home 命中率告警**
   - 阈值默认 `HOME_CACHE_HIT_RATE_MIN=0.35`，样本 `HOME_CACHE_ALERT_MIN_SAMPLES=20`
   - `homeCache.alert` 进 health / `/api/metrics/home-cache`
   - `AlertsService` kind=`home_cache_hit_rate`；运营台中文横幅 `#homeCacheAlertBanner`
4. 波次：`M47-sse-path-ticket-research-resume-home-alert` · `maturityApprox=0.997`

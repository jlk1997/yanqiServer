## 本波交付

1. **冲突全量导出**
   - `GET /api/imports/enterprise/jobs/:id/conflict-export.csv`（始终全量）
   - `GET /api/imports/enterprise/jobs/:id/conflict-export.zip`（CSV + `summary.json`）
   - 预览接口保留抽样；`?full=1` / `conflict-preview.csv?full=1` 也可要全量
   - 运营台 + 续跑卡：全量 CSV / ZIP 按钮
2. **SSE 短票可选绑 jobId**
   - `POST /api/jobs/sse-ticket` body 可带 `jobId`
   - 开流 `?id=` / 路径上的 job 与绑定不一致 → **401 `SSE_TICKET_JOB_MISMATCH`** 且**不消费**
   - 前端 `withSseAuth` / ops `sseUrl` 自动从 URL 抽 jobId
3. **科研进行中 matchedOrgIds 快照**
   - 匹配写入过程中累加供给机构 id → liveJobs / JobLog.payload / progress
   - `GET /api/jobs/resume-cards?shell=research`：除 Match 反查外，进行中快照命中本单位也会出卡
4. **home 分壳命中看板**
   - `recordHomeCache(kind, shell)`；`/api/metrics/home-cache` 与 health 含 `byShell`
   - 运营台「延迟/队列」页：分壳 HIT/MISS 表 + 刷新按钮
5. 波次：`M48-conflict-full-export-sse-job-bind-research-snapshot-home-shell` · `maturityApprox=0.998`

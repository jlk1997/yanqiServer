# 研企通 · 加固（M49）

> 大白话：冲突全量导出遇到大表不再卡死请求——**异步任务 + 进度/取消/就绪下载**；SSE 短票按**租户配额**（超限 **429 中文**）；科研壳看见进行中 `matchedOrgIds` 快照会记**审计**；home 分壳命中写入 **持久曲线**（图表友好 JSON）。交付心态仍按「做到像 200%」；测量综合约 **99.9%**（实质加固，**不是虚报 100%**）。**支付维仍约 45%**（无真 PSP，从不真扣款）。票仓继续 **memory+file**，不强制 Redis。

## 本波交付

1. **冲突大文件异步导出**
   - `POST /api/imports/enterprise/jobs/:id/conflict-export/async`（`format=csv|zip`）
   - `GET .../conflict-export/jobs/:exportId` 进度；`POST .../cancel`；`GET .../download`；`GET .../stream` SSE
   - `GET /api/imports/enterprise/conflict-export/async/meta`（阈值默认 5000，可用 `CONFLICT_EXPORT_ASYNC_THRESHOLD`）
   - 运营台：异步大文件导出 / 取消 / 下载 + 进度条
2. **SSE 短票按租户配额**
   - mint 时滑动窗口计数；超限 **429** `SSE_TICKET_TENANT_QUOTA` + `messageZh`
   - `SSE_TICKET_TENANT_LIMIT`（默认 40）/ `SSE_TICKET_TENANT_WINDOW_MS`（默认 60s）
   - 成功 mint 响应带 `quota.remaining`
3. **科研快照审计**
   - 科研壳续跑卡命中进行中 `matchedOrgIds` 快照时落盘（同 actor+job 默认 60s 去重）
   - `GET /api/jobs/research-snapshot-audits`（运营）；文件 `.data/metrics/research-snapshot-audit.jsonl`
4. **home 分壳命中持久曲线**
   - 写入 `.data/metrics/home-cache-curve.json`
   - `GET /api/metrics/home-cache/curve`（`labels` + `series` 图表友好）；`POST .../curve/flush`
   - 运营台曲线摘要 + 科研快照审计面板
5. 波次：`M49-async-conflict-export-sse-tenant-quota-snapshot-audit-home-curve` · `maturityApprox=0.999`

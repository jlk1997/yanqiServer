## 本波交付

1. **导出租户配额告警徽章**
   - `GET /api/imports/enterprise/conflict-export/async/quota-warnings`
   - 软阈值默认 80%（`CONFLICT_EXPORT_TENANT_SOFT_RATIO`），危急 95%（`CONFLICT_EXPORT_TENANT_CRITICAL_RATIO`）
   - `meta.quotaWarnings` 一并返回；运营台「快慢与队列」旁徽章 + 明细
2. **科研快照审计异步大导出 + 脱敏档**
   - 同步：`GET .../research-snapshot-audits.csv?redaction=full|partner|public`
   - 异步：`POST .../export/async` → progress / cancel / download
   - partner：掩码 actor、哈希租户/机构、截断 jobId、去掉 org 样本
   - public：日期级、匹配数分桶、去掉身份字段
3. 波次：`M52-export-quota-badge-audit-async-redact` · `maturityApprox=0.999`

# 研企通 · 加固（M55）

> 大白话：从 M41–M54 的导出/SSE/配额加固**回摆核心链路**——**匹配一页纸**与**导入冲突预览**的首屏延迟、字段投影、短缓存/ETag，以及匹配/导入/续跑/一页纸全流程的等待·取消·成功·401/403 中文反馈密度。测量综合诚实约 **99.9%**，**不虚报 100%**。支付维约 **45%**（无真 PSP）。

## 本波交付

1. **一页纸首屏瘦身**
   - 默认 `fields=sheet&slim=1`：跳过反馈权重/近期反馈/软重算，只算 sheet 正文
   - 短缓存（默认 8s）+ ETag + `If-None-Match`→304；响应带 `timingMs` / `cache` / `payloadMode`
   - `match-sheet.html`：骨架屏、busy 条、成功 toast；一页纸优先绘制，me/tiers/台账并行不挡首屏
2. **冲突预览首屏**
   - 机构 **批查**（`findMany` 替 N+1 `findFirst`）
   - `fields=summary|slim|rows`；短缓存 + ETag；`timingMs` / `batchOrgLookup`
   - 运营台 / 续跑卡：先摘要再 slim 行明细，骨架 + busy + toast
3. **核心反馈密度**
   - 一页纸打开/分享：等待、成功、401/403 中文安全提示，避免静默挂起
   - 冲突预览与草稿清理同样走 busy/toast
4. **轻量可选**：`POST /api/metrics/alerts/webhook-draft/cleanup` + 运营台「清理过期Webhook草稿」
5. 波次：`M55-core-latency-feedback` · `maturityApprox=0.999`

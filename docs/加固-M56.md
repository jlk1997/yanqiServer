## 本波交付

1. **匹配跑批写库热点**
   - 供给向量 **一次预热**：复用库内 embedding，缺失才 embed；分块并行 update + sync
   - 每需求打分后：**批查联系人** + `createManyAndReturn` 写 MatchResult + `createMany` 写 Lead
   - 需求向量有则复用；软取消与进度条仍按需求/写入边界准确
2. **导入写库热点**
   - 按块（默认 20）**批查机构**（creditCode/name），块内复用 Map，进度 `row-write-batch`
   - 软取消仍在行/块边界生效；差分续跑键不变
3. **解释页残余延迟 + 反馈**
   - `explain`：权重/反馈/信任 **并行**；`fields=core|full`；短缓存 + ETag + `timingMs` · wave `M56`
   - 运营台「看贡献分」：骨架 + busy + toast；401/403 中文安全提示；M17 金标区复用首屏，避免二次请求
4. **E2E 无静默**
   - 同步跑匹配 busy/toast；企业发需求 busyText + 401/403
   - 冒烟：demand→match→one-pager、explain cache HIT、import→conflict-preview、UI 反馈字符串
5. 波次：`M56-core-match-import-batch` · `maturityApprox=0.999`

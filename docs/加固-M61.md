2. **收件箱 cursor ETag 短缓存**

   - 短 TTL + `ETag`；未变 `304` / `X-Inbox-Delta-Cache: HIT`
   - 前端 `useEtagCache`；busy/toast 中文清理
3. **冲突预览投影 demand/person 写库计划**

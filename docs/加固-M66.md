## 本波交付

1. **自适应 score/write 分片背压**
   - 依据近期写库分片耗时动态收缩/扩张 `MATCH_DEMAND_PARALLEL` / `MATCH_WRITE_SHARD`
   - 软取消仍在块间/片间生效；中文进度展示「自适应背压：并行 x · 写片 y · 近均 zms」
   - 回包 `adaptiveBackpressure` / `adaptiveProgressZh` / `adaptiveKnobsZh` · `wave=M66`
2. **自愈后 HIT 探测闭环（干跑）**
   - `POST .../alerts/self-heal` 默认 `probeAfter=true`：bust + 样本重写后，对壳做短环 HIT/MISS/304 探针
   - `POST .../alerts/self-heal/probe` 可单独重跑；运营台「自愈后 HIT 探测」+ 中文 toast/对话框
   - 通知仍干跑；**不真外发**；不扩张导出/SSE/配额
3. **冲突 rowIndex 精确对齐**
   - slim 行带 `rowIndex`；demand/person 写库投影按本页 `pageRowIndexes` 过滤，create/update 均带 rowIndex
   - `demandPersonWritePlan.rowIndexAlign=true`；中途取消仍 AbortController；401/403 中文
4. 波次：`M66-core-adaptive-bp-hit-probe-rowindex-align` · `maturityApprox=0.999`

## 环境旋钮（文档）

| 变量 | 默认 | 含义 |
|------|------|------|
| `MATCH_ADAPTIVE_BP` | `1` | `0` 关闭自适应，固定基线 |
| `MATCH_DEMAND_PARALLEL` | `2` | 并行基线（1–4） |
| `MATCH_PARALLEL_MIN` / `MAX` | `1` / `4` | 并行可调上下限 |
| `MATCH_WRITE_SHARD` | `25` | 写库分片基线 |
| `MATCH_WRITE_SHARD_MIN` / `MAX` | `5` / `80` | 写片可调上下限 |
| `MATCH_BP_SLOW_MS` | `400` | 近均 ≥ 此值收缩 |
| `MATCH_BP_FAST_MS` | `80` | 近均 ≤ 此值扩张 |
| `MATCH_BP_WINDOW` | `6` | 滑动窗口样本数 |
| `MATCH_SCORE_CHUNK` | `80` | 打分块（可取消，不参与背压） |

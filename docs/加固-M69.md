## 本波交付

1. **ANN 召回预热池 · 候选去重**
   - `MATCH_ANN_PREWARM_POOL=1`：对后续 N 条需求预取 `nearestCapabilities/Outcomes`（`pgvector_hot`）；无扩展记 `app_skip` 不硬改向量基建
   - 打分前按 `kind:id` 去重；软取消清空池并停 inflight
   - 中文进度含 ANN 池命中/去重；回包 `annRecallPrewarmPool` · `annRecallPrewarmPoolZh` · `wave=M69`
   - 与 M65 pipelineOverlap、M67 supply×score、M68 demand-embed lookahead / 召回背压并存
2. **壳趋势拐点告警 + 复探针回升判定**
   - `detectShellTrendInflection`：近段相对前段持续下行 → 中文拐点告警
   - 自愈/探针：复探针后 `judgeShellHitRecoveryAfterReprobe` → recovered / still_low 中文 toast
   - 双通道干跑正文可带拐点/回升文案；**不真外发**；不扩张导出/SSE/配额
3. **仅确认行续跑 · 跨页决策摘要**
   - `POST .../resume` 支持 `confirmOnly=true`：只写显式确认行（未决不写）
   - 预览/决策/统一任务卡带 `crossPageDecisionSummary`（确认/跳过/未决/将写）
   - UI：任务卡「仅确认行续跑」+ 冲突页同名按钮；中页取消仍在；401/403 中文
4. 波次：`M69-core-ann-pool-shell-inflection-confirm-only` · `maturityApprox=0.999`

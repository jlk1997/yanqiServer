## 本波交付

1. **ANN 池 × 供给嵌入统一取消令牌 · 召回 miss 轻量扩窗**
   - 同一 soft-cancel token：latch 后 ANN 预热池清空 + 供给补齐同停
   - `MATCH_RECALL_LIGHT_EXPAND=1`：候选过少/召回空时有界二次 nearest（factor×、封顶 max），不无限扩窗
   - 中文进度含轻扩；回包 `unifiedSoftCancelToken` · `recallLightExpand` · `wave=M70`
   - 复用既有 ANN/pgvector 路径，无扩展记 app_skip
2. **拐点后建议 bust 壳 + 回升 SLA**
   - 拐点告警后 `applySuggestedBustAfterInflection` 写入建议壳列表到壳健康 JSON
   - 开 `recoverySla` 窗口（默认 15min）；复探针 recovered 结算 time-to-recovered，超时 breached
   - 中文 toast；双通道干跑可带建议 bust/SLA 文案；**不真外发**；不扩张导出/SSE/配额
3. **未决行批量决策向导 · 仅确认续跑游标对齐**
   - `POST .../undecided-wizard`（或 row-decisions `undecidedAction`）：只动未决，可按 slim offset/limit 页窗
   - 仅确认续跑带 `slimOffset/slimLimit/pageCursor`，`confirmOnlyResumeCursor` 对齐 rowIndex，避免错页重写
   - 中文标签「未决全确认/全跳过」；中页取消仍在；401/403 中文
4. 波次：`M70-core-unified-cancel-light-expand-bust-sla-undecided-wizard` · `maturityApprox=0.999`

## 本波交付

1. **demandId 级召回/打分检查点续跑**
   - 每条需求持久化 `pending→recall→score→write→done/skipped` 检查点
   - 取消后 `resumeCursors.demandCheckpoints` + `lastUnfinishedDemandId`；续跑自未完成 demand 起，不重做已完成
   - 统一任务卡中文进度；软取消与 `scope=embed|score|all` 细取消仍可用
2. **多日钻取本地对比卡 + 倒计时结束自动复探针**
   - `day-drill?multiDay=1` 返回 `localCompareCard`（本机并排 HIT/注解，无外发）
   - 冷却 `countdownSec` 归零后可选自动复探针：`POST .../countdown-end-auto-reprobe`（仅干跑通知）
   - 运营台本地对比卡 / 自动复探针开关；中文 toast
3. **scrubber 暂停+定点还原 + 跨行批量字段决策**
   - 差分播放可暂停/继续；seek 到 seq 并调用 restore
   - `field-decisions` 支持 `batch.rowIndexes + field + decision` 跨行批量；即时改写写库预演
   - 中文标签；中页取消仍可用
4. 波次：`M78-core-demandid-score-recall-checkpoint-resume-multiday-local-compare-countdown-autoreprobe-scrubber-pause-seek-batch-field` · `maturityApprox=0.999`

# 向量模式与队列

## EMBEDDING_MODE

| 值 | 条件 | 说明 |
|----|------|------|
| `hash`（默认） | 无外部依赖 | jieba-wasm + 产教领域词表切词，再做哈希向量。离线可跑。 |
| `openai` | 需 `OPENAI_API_KEY` | 调 OpenAI Embeddings；可设 `OPENAI_BASE_URL` / `OPENAI_EMBEDDING_MODEL`。失败自动回退 hash。 |
| `local` | 需 `EMBEDDING_URL` | POST `{ "text": "..." }`，期望返回 `{ "embedding": number[] }` 或直接数组。可选 `EMBEDDING_TOKEN`。失败回退 hash。 |

相关代码：`packages/shared/src/embed.js`、`lexicon.js`。

## 队列

- 配置了 `REDIS_URL` 且能 ping 通：API 用 **BullMQ** 跑匹配/采集。
- 否则：**进程内队列**（与 MVP 行为一致）。
- 运维台「任务」页可看 `GET /api/jobs/status`。

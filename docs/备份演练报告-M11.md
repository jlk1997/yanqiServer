# 备份演练报告 · M11

> 演练时间（Asia/Shanghai）：2026-11-01 21:50–21:51  
> 环境：本机 box · embedded Postgres `127.0.0.1:54329` · 业务库 `yanqi_match`  
> 命令：`npm run backup:drill` → `npm run restore:drill`  
> 产物目录：`backups/drill-2026-11-01T13-50-54/`

## 结论（诚实）

- **通过**：JSON 全量快照 + 附件清单哈希核对 + scratch schema 计数往返一致。  
- **未用 pg_dump 成功**：系统 `pg_dump` 17.11 与服务器 18.6 版本不匹配；embedded 包只带 `postgres/initdb/pg_ctl`，**不带 pg_dump**。本轮以 JSON 快照为权威备份介质，不假装「已有二进制级 PITR」。  
- **恢复策略**：不向生产表灌 dump；在 `yanqi_restore_drill` schema 写入计数校验表，并对照 live 行数与附件 sha256。

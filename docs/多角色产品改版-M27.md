# 研企通 · 多角色产品改版（M27）

> 大白话：不能所有人登进来都看见同一坨「采洗配联」黑屏瀑布流。谁干什么，首页就只给他干什么。

## 问题（对照现状）

- `/` 默认进运营中台，侧栏三十多个入口，默认还停在采洗配联长页。
- 门户 `portal.html` 把企业/高校揉成同一个「机构工作台」，信息流不分侧。
- 后端其实已有 ADMIN / OPERATOR / BROKER / TENANT_ADMIN / ORG_USER，但登录后几乎不分流。
- 体验像内部工具堆功能，不像商业化 SaaS。

## 四种主角色（可扩展壳）

| 角色壳 | 谁 | 默认首页 | 今天先干啥 |
|--------|----|----------|------------|
| `enterprise` | 企业用户（ORG_USER/TENANT_ADMIN + 企业组织） | `/work-enterprise.html` | 发需求、看匹配推荐、跟对接进度 |
| `research` | 高校/实验室（ORG_USER/TENANT_ADMIN + 高校/院所） | `/work-research.html` | 上架能力/成果、看谁找我、补档案 |
| `broker` | 经纪人 / TTO / 园区撮合 | `/work-broker.html` | 待跟进单、SLA、推进状态 |
| `ops` | 平台运营 / 超管 | `/ops.html` | 采洗配联、匹配复核、租户与审计 |
| `guest`（预留） | 政府/园区访客只读 | 以后 `/work-park.html` | 看看板，不写业务 |

映射规则：`role` 优先（ADMIN/OPERATOR/OPS_VIEWER→ops，BROKER→broker）；机构角色再看 `org.type`。没绑组织 → 门户认领引导。

## 导航原则

1. **登录后直达本职首页**，不让企业看见运营采集台。
2. 每个首页：**三件今天要做的事 + 几张关键数字卡 + 最近几条**，不无限往下滚当主交互。
3. 进阶能力折叠进「更多」；运营台侧栏分组，默认展开「今天 / 对接」，其它收起。
4. 公开广场仍在 `portal.html`，工作台与逛广场分开。
5. 演示账号一键切换，方便试点讲解。

## 砍 / 藏什么

- 企业/科研壳：**不展示** 采集任务、SMTP、租户、Webhook、向量迁移等运营件。
- 经纪人壳：只留分派、跟进、SLA、话术入口；不进飞轮。
- 运营壳：保留能力，但首页改成「今天待办」而非默认飞轮长页。

## 成功标准

- 四个演示号登录后落到不同壳，30 秒内能说出「我该点哪」。
- `npm run gate` 绿；健康检查波次 `M27-multi-persona`。
- 诚实成熟度略升（信息架构与可用工作台），不为堆功能虚涨。

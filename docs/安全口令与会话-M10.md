# 安全：口令哈希与会话吊销（M10）

## 口令哈希

- 当前算法：**Node.js `scrypt`**，存储格式 `scrypt$salt:hash`（兼容旧 `salt:hash`）。
- **不是**明文，也不是 MD5/SHA1 单次哈希。
- 更高安全等级可迁 **argon2id**（需加依赖与离线重哈希任务）。演示/早期试点 scrypt 可接受；上线前按合规要求评估。
- 登录响应里的 `passwordHashing` 仅返回算法元信息，**从不回传哈希本身**。

## 会话吊销

- 登录签发 JWT 风格令牌时写入 `jti`，并落库 `AuthSession`。
- `POST /api/auth/logout`：吊销当前会话并清 Cookie。
- `GET /api/auth/sessions`：列出会话。
- `POST /api/auth/sessions/:jti/revoke`：吊销指定会话。
- `POST /api/auth/sessions/revoke-others` / `revoke-all`：批量吊销。
- API 中间件对带 `jti` 的请求查库；已吊销则视为未登录。

## 审计导出

- `GET /api/audits/export?format=json|csv&limit=1000`（需运营登录或 API Key）。

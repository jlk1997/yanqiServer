# 高校/实验室 ↔ 企业需求 产教融合匹配平台 — 开源选型调研

**日期：** 2026-10-28（Asia/Shanghai）  
**范围：** 中国导向的 B2B 双边数据积累 → 能力/成果归档 → 打分匹配 → 找人触达 → 官网/邮件通知  
**方法：** 多源 WebSearch + 仓库 API 核验（stars / license / pushed_at）；不收录无法核验或明显伪造的仓库  
**原则：** 优先合法公开 API / 官方开放数据；禁止付费墙站（如 CNKI）违规爬取方案进入主栈

---

## 0. 业务链路映射（用户流程 → 技术层）

| 业务步骤 | 技术层 | MVP 目标 |
|---------|--------|---------|
| 1. 双边爬取/积累 | A 学术 + B 企业 | 合法 API/公开库冷启动；人工补录高价值名单 |
| 2. 能力/成果 vs 需求归档 | G 知识库 + 自研 schema | 统一「能力卡 / 需求卡」结构化 |
| 3. 分析打分配对 | C 匹配引擎 | 可解释分数 + Top-N 推荐 |
| 4. 找人 | E CRM + F 触达 + 人工 BD | 联系人线索 + 社媒/邮件 |
| 5. 通知 | F 邮件/工作流 + 官网消息 | AI 草稿人审后发 |

**结论先行：** 全球几乎没有「开箱即用的中国产教融合双边匹配 SaaS」成熟开源。GitHub/Gitee 上校企类项目多为实习就业教务系统（星少、停更），不能当核心。正确做法是 **自研匹配与档案中台**，外围拼成熟 OSS。

**A 层结论**
- **主选：** OpenAlex + PyAlex（机构/实验室画像、论文、主题、作者 ORCID）+ Crossref 补 DOI。
- **辅选：** Semantic Scholar（相似论文推荐、引用图）。

## 2. 法律与合规红线（必须写进方案）

1. **CNKI / 知网、万方等付费库：** 禁止未授权批量爬取；用 OpenAlex/Crossref/机构绿通/正式采购。  
2. **Google Scholar / Google Patents 刮取：** 无官方 API、易封禁、ToS 风险 → 仅人工抽样，不作生产爬虫。  
3. **国家企业信用信息公示系统 / 天眼查类「开源接口」仓：** 多为未授权封装 → **不用**；采购企查查等开放平台。  
4. **邮件与个保法：** 冷启动触达需合法来源联系方式、退订、目的限定；AI 只写草稿，人审。  
5. **AGPL / Fair-code：** Twenty、Espo、Firecrawl、Neo4j Community、mailcow(GPL) —— 改源码并作为网络服务提供时，评估开源义务或买商业许可。  
6. **Dify：** 未获书面授权不得用源码运营多租户云。  
7. **n8n SUL：** 自家后台自动化可以；把工作流搭建能力卖给租户要 OEM/企业协议。

### 建议数据模型（最小）

```
Institution / Lab / Researcher / CapabilityCard / ResearchOutput(paper|patent|project)
Enterprise / NeedCard / Contact
MatchScore(capability_id, need_id, score, reasons_json)
Lead / OutreachTask / MessageLog
```

### 匹配分数建议（可解释，MVP）

参考 PatentPilot 思路，示例权重（可配置）：

1. **主题/关键词/IPC/学科 overlap** 40%  
2. **向量语义相似度**（摘要↔需求描述）30%  
3. **地理/产业/成熟度（TRL）** 15%  
4. **合作史/论文合作单位命中** 10%  
5. **时效（近 3 年产出）** 5%  

每条匹配输出：`score` + `reasons[]`（人话），供销售筛选。

### 6–8 周 MVP 切片

1. **W1–2：** OpenAlex 按目标高校机构拉作品/作者；手工导入 50 家企业需求卡；Postgres schema。  
2. **W3–4：** 能力卡抽取（LLM via Dify）+ embedding + 打分 API + 管理后台列表。  
3. **W5–6：** 线索看板；n8n：高分匹配 → 生成中英邮件草稿 → 人审发送；官网「匹配结果」只读页。  
4. **W7–8：** Crawl4AI 补实验室公开页；接入一家工商 API；AiToEarn 试一条行业内容触达。

**方法：** GitHub Search API + `api.github.com/repos` 核验（stars / license / pushed_at）+ WebSearch/WebFetch + Gitee API 探测；**不收录无法核验或明显伪造的仓库**  
**用户主张：** 「肯定是有的」——本轮目标是把**概念最接近、可 fork 改造**的真实仓库尽量挖全，而不是只重复「没有整包成品」。

## 0. 结论（先说清楚）

1. **仍没有**可直接白标、覆盖「双边爬取 → 能力/成果归档 → 可解释打分匹配 → 找人 → AI 邮件通知」全链路、且面向**中国产教融合 / 课题转移**的成熟开源 SaaS 成品。  
2. **科易网、火石创造、转果果、InnoMatch、中关村技术交易平台、深圳科交中心等商业/地方平台：本轮未找到公开开源核心代码**（仅有产品站与案例文；Gitee/GitHub 无对应主仓）。  
3. **但第二轮挖到更多「可直接 fork 的半成品 / 邻近整包」**，按链路适配度排序后，**最值得动手的 5 个**是：  
   - **demand-chain**（链路覆盖最全，含爬虫+匹配+邮件+学术检索）  
   - **WorkMesh**（可解释供需/技能匹配多端原型，MIT，★95）  
   - **COOPERA-UFBA**（企业需求 ↔ 高校研究组 marketplace，概念最近）  
   - **OpenOutreach / Quickly / warmbly / harvey**（找人+冷邮触达层大幅补强）  
   - **Lemma / InnoForge / paper2patent / Salesforce TTO Starter**（成果侧归档与转化评估）

**诚实表述：** 「有」的是**可拼装的真实开源零件 + 若干接近业务的半成品**；「没有」的是**科易网级成品开源替代**。用户可以 fork 上述半成品加速，而不是从零空想。

## 2. 「完整产品叙事」最接近的半成品（深挖）

### 2.1 demand-chain — 本轮仍是「全链路叙事」第一

- **做什么：** 需求库 + 供应商库 + 爬虫定时任务 + TF-IDF/分类/IPC 匹配 + 邮件通知 + 科研工作台（PubMed/CrossRef/OpenAlex/S2）+ MCP Server（70+ tools）。  
- **为何排第一：** 用户链路五环里它自称覆盖了**爬、档、配、邮、学术**；代码仓有 `crawled_demands_*.json`、`crawled_suppliers_*.json`、Docker、Alembic，不是空 README。  
- **风险：** ★0；数据源偏海外挑战赛/创新平台；中国高校实验室与企查查级企业侧需自换；生产可靠度未知。  
- **建议：** **fork 当后端骨架**，把「供应商」改成「实验室/成果卡」，「需求」对齐企业技术需求 schema，匹配理由字段强化可解释性。

### 2.2 WorkMesh — 可解释匹配 + 多端产品最完整的 MIT 原型

- **URL：** https://github.com/yangyunice/WorkMesh  
- **★95 / MIT / 2026-06 推送**  
- **能力：** 个人技能画像 ↔ 企业岗位/需求；匹配分数+依据；企业端/个人端/治理端；RAG + Agent Skills；Docker 一键。  
- **改造点：** 把 `PersonalSkill` / `Job` 映射为「实验室能力/成果」与「企业课题需求」；保留可解释匹配 API（`GET .../jobs/:id/matches`）。  
- **注意：** 作者自述大量 AI 生成代码，需做安全与测试加固后再商用。

### 2.3 COOPERA-UFBA — 业务题干几乎同款

- **URL：** https://github.com/MATE85-UFBA/IC045-marketplace-ufba  
- **叙事：** 连接**市场技术需求**与 **UFBA 研究组**；apps/api + apps/web；Nest + Next + Postgres。  
- **局限：** ★2、课程项目、无明确 license、无爬虫/AI 匹配深度。  
- **建议：** 当 **角色模型与页面流程参考**（企业发需求、研究组接、管理员审核），匹配引擎另接。

### 2.4 Capstone / LinkBridge / FYP-Market — 校企「项目市集」一族

| 仓 | 价值 | 缺口 |
|----|------|------|
| Capstone Connect | MIT；企业发题、学生兴趣、审批流 | 无科研能力画像、无爬虫 |
| LinkBridge | 三角色+支付+进度 | 星 0；偏学生项目众包 |
| FYP-Market | README 叙事含 AI matching | 无 license；README 拉取 404 |

适合「后期销售拓展前的对接 UI」，不适合当数据与匹配核。

## 9. Gitee / 中文关键词检索说明

- Gitee API `search/repositories` 对本轮多个中文 query **返回空数组**（可能限流或索引弱）；网页搜索也被拦。  
- GitHub `in:name,description` 对「产教融合/校企合作/供需对接」等 **total≈0–1**，噪声仓居多。  
- 中文「成果转化」命中质量最高的可核验仓是 **paper2patent（★696）**、**demand-chain**、**InnoForge**、**ylian-b2b**，以及大量**实习教务/毕设**（适配度低）。  
- 中国校企类 GitHub 仓（如 ZHoodLum 实习系统、dafeng 校企办学流程）**偏教务就业，不是成果转化匹配**。

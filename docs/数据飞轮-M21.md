# 研企通 · 数据飞轮（M21）

## 目标

冷启动靠 **先堆量**：高校/实验室成果与能力 ↔ 企业/政府需求，再清洗、匹配、找人。  
不是先做支付和域名。

## 主路径

**采 → 洗 → 配 → 联**

1. **采**
   - 高校：`npm run crawl:openalex` 或运营台「采洗配联 → 采集高校」。OpenAlex 公开 API，分页+限速；失败回落演示夹具。
   - 企业：授权 CSV（`data/templates/enterprise-authorized-import.csv`）或 `npm run crawl:demands` 演示夹具。
2. **洗**：`POST /api/flywheel/clean` — 重复/缺字段/垃圾标题扫描、行业标签粗推测、TRL/许可启发式补全；质检台可批量勾「已处理」。
3. **配**：原有匹配复核。
4. **联**：线索发信、经纪人跟进。

## 合规红线

| 可以 | 不可以 |
|------|--------|
| OpenAlex 公开接口 | CNKI / 知网灰爬 |
| 单位授权的 CSV/JSON 导入 | 未授权企查查/工商库爬取 |
| 仓库内「演示夹具」 | 把演示数据冒充真实工商库 |

## 运维按钮

运营台 → **采洗配联**：刷新库存、采集高校、导入演示需求、清洗、洞察、迷你流水线。

## M23 附录（授权多文件 / 净增 / 隔离跳过）

1. **多文件导入**：运营台拖 CSV/JSON → `POST /api/flywheel/import-files` 先出人话校验报告（哪行错、sampleFix），`commit=true` 才写好行。样例：`data/imports/m23-authorized-*.csv|json`。
2. **隔离不进匹配**：`extensions.quarantine=true` 的需求/能力/成果在 `runMatch` 直接跳过；任务日志会写「跳过隔离…」。
3. **净增条**：仪表盘 `netNewStrip` = 本周 vs 上周新建量（需求/成果/能力），真实 DB 计数。
4. **门户一句话**：`POST /api/portal/demands/parse-one-line` → 确认 → `publish-one-line`（确认后一键发布）。

## M24 附录（增量去重 / 列映射 / 可匹配清单）

1. OpenAlex：`openAlexId` / `doi` / `title+org` 命中则跳过，不再 upsert 覆盖；JobLog 含 `newOutcomes`、`skippedDup`、`sampleSkips`。
2. `GET /api/flywheel/week-match-ready`：本周新建且未隔离的需求/成果/能力。
3. `POST /api/flywheel/import-files` 支持 `mapping`；返回 `mappingSuggest`、`badRowsCsv`。
4. 匹配结果含 `skippedDemandSamples` / `skippedSupplySamples`。
5. `parseDemandPaste` 返回 `hints` / `thin`。

## M25 附录

1. `OPENALEX_FILL_EMPTY=1` / API `fillEmpty: true`：撞库仅补空。
2. `POST /api/flywheel/week-match-ready/run`：`demandIds` + `enqueue?`。
3. 列映射记忆：`.data/import-column-maps.json`（header signature）。
4. parse 返回 `confidence`；门户高置信直发 + 撤消删除。

## M26 附录（三刀收束）

1. 列映射：`.data/tenants/<tenantId>/import-column-maps.json`（default 兼容读旧全局文件）。
2. `POST /api/flywheel/fill-empty/preview` → diff；`confirm` 才写。
3. `POST /api/flywheel/week-match-ready/run` 返回 `jobId`；`GET .../jobs/:id`；`POST .../jobs/:id/cancel`。

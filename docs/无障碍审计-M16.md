# 无障碍审计 · M16

审计范围：运维台 omnibox、门户对接看板、主要登录/套餐表单。日期：2026-11-01（Asia/Shanghai）。

## 已修

| 项 | 改动 |
|----|------|
| 跳过链接 | 运维/门户增加「跳到主内容」 |
| 焦点环 | `:focus-visible` 统一描边；`sr-only` 工具类 |
| 运维搜索 | `role=combobox`、`aria-expanded`、`aria-controls`、结果 `listbox`/`option`；方向键移动 |
| 门户看板 | 卡片 `tabindex=0`、`aria-label`；← → 键盘挪列；区域 `aria-label` |
| 登录框 | 主要输入补 `aria-label` |
| 用量区 | `aria-live=polite` 更新提示 |

## 仍待（诚实）

- 运维侧栏大量按钮未做成完整 `aria-current` 路由宣告
- 对话框 `showDlg` 未做焦点陷阱
- 图表/解释面板对比度未系统抽查
- 未跑 axe/Lighthouse 全量 CI（本波手工+代码修补）
- 移动底栏与看板在极端缩放下的触控目标尺寸未量化

## 原则

先修高频路径；不宣称 WCAG 2.2 AA 全过。

# 权限矩阵 · M14

角色：

| 角色 | 中文 | 说明 |
|------|------|------|
| ADMIN | 平台超管 | 全开 |
| OPERATOR | 运营 | 写运营台，不含硬删等超管专属时可再收 |
| OPS_VIEWER | 运营只读 | 只读运营数据；可管自己的会话/告警确认 |
| BROKER | 经纪人 | 跟进匹配/线索 |
| TENANT_ADMIN | 机构管理员 | 本组织写 + **邀请同事** |
| ORG_USER | 机构成员 | 本组织读写卡片/对接 |

接口：`GET /api/auth/permissions` 返回机器可读矩阵。

强制点：

- 中间件拦截 OPS_VIEWER 的写、TENANT_ADMIN/ORG_USER 的平台运营写  
- 协作邀请需 `org.invite`（TENANT_ADMIN / ADMIN / OPERATOR）  
- API Key 视为超管

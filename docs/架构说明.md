# 架构说明（MVP 落地版）

## 运行时

- **API**：NestJS，全局前缀 `/api`，静态托管运维台。
- **DB**：PostgreSQL（Docker pgvector 或嵌入式）。Embedding 字段为 JSON 数组。
- **任务**：`JobsService` 进程内队列；采集子进程调 worker 脚本；匹配可 API 内同步或入队。

## 数据流

采集（OpenAlex/CSV）→ Organization / Outcome / Capability / Demand / Person  
→ Match Worker 打分 → MatchResult + Lead（邮件草稿）→ 运维复核 →（后期）SMTP/AiToEarn

## 扩展点

- `extensions` JSON：学校个性字段不进主流程分支
- `EMBEDDING_MODE`：hash → openai / sentence-transformers
- BullMQ：接 Redis 后把 `JobsService` 换成队列生产者
- Dify：替换 `buildOutreachDraft` 模板写稿

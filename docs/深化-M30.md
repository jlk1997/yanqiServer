## 本波交付

1. **一页纸导出**：浏览器打印 / 服务端 HTML 附件 / Chrome headless PDF；中文排版。
2. **园区审批流骨架**：征集窗 `draft→open→closed→archived`；审批 `submitted→under_review→approved|returned|rejected→published`。
3. **经纪人佣金可读对账**：汇总 + 明细；无分成时幂等灌演示账；运营台可刷新。
4. **五壳空状态 / a11y**：园区/经纪人空态补下一步；打印时隐藏导航。
5. **门禁**：`npm run gate`；波次 `M30-export-park-ledger`；诚实综合约 **94.5%**。

## 本波交付

1. **审批 → 案例池一键**：已通过/已公示可脱敏发布；幂等；可顺带转到「已公示」。
2. **一页纸分享 ACL**：导出/接口按 `tier` 裁剪；`POST .../share` 生成链接；公开 token 可读。
3. **成交自动对账**：经纪人标记成交后账本新建或升格，带 `originZh` / `reconciledAt`。
4. **五壳 UX**：园区/企业/科研/经纪人大厅提示条；冷静空态与下一步。
5. **门禁**：`npm run gate`；波次 `M31-case-share-reconcile`；诚实综合约 **95.5%**（支付仍约 **18%**）。

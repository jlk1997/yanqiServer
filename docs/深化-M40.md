## 本波交付

1. **五壳办事窗信息密度与空状态**：enterprise / research / broker / park / ops；空态单 CTA；大白话。
2. **移动剧本 + 一页纸动线**：`YB.bindPlaybookDeck`；`openMatchSheet` 少点击脚栏；`match-sheet` sticky 导出。
3. **a11y basics**：focus-visible、对比度、主 CTA / 登录表单 aria、skip-link。
4. **门禁**：`npm run gate`；波次 `M40-ux-density-empty-a11y-playbook`；`maturityApprox=0.990`（禁止通胀）。
5. **刻意不抬分**：无真 PSP / 政务专网 / 电子签 / 真人试点 CSV 反馈前，测量分停在天花板。

# 研企通 · 竞品对标（成熟产品视角）

调研日期：2026-11-01（Asia/Shanghai）。公开官网/科技部报道/商务委案例交叉核验。目标：找出成熟产品必备能力，以及研企通要超越的空隙。

## 1. 竞品地图（谁在干什么）

| 竞品 | 类型 | 核心卖点 | 主要用户 |
|------|------|----------|----------|
| **科易网** | 民营技转数智平台 | 知识图谱 + 大量「智成」工具（推介书/评价/应用图谱）+ 高校专题白标 | 高校 TTO、地方科技局、经纪 |
| **转果果**（北京智服平台） | 政府指导 AI 匹配平台 | 五大库 + 专属大模型 + 多层次匹配 + 线下沙龙；试运营偏医疗器械 | 京内高校院所、企业、技术经理人 |
| **InnoMatch** | 国家级技术要素市场数字化入口 | 需求导向、全球渠道、技术经理人协作分成、产业创新中心 | 大企业需求方、成果方、经纪人 |
| **上海国际技术交易市场 / 科技大市场** | 线下枢纽 + 线上平台 | 国际渠道、长三角协同、合同落地 | 政府、园区、跨境技术贸易 |
| **火石创造 / 火石数链** | 产业数据与智能体 | 产业大脑、招商/科技金融智能体；医药供需偏垂直 | 政府园区、银行、生物医药链 |
| **万企千校等产教平台** | 产教融合 / 实习就业 | 岗位、实训、教材共建，**弱成果转化撮合** | 高校教务、企业 HR |
| **AUTM AIM（海外）** | 大学可许可技术目录 | 专利/技术挂牌、对接 TTO；目前市场侧曾暂停重整 | 高校 TTO、产业 BD |

结论：真正和研企通同赛道的是 **科易网 / 转果果 / InnoMatch** 一类「成果↔需求智能对接」；火石偏产业数据与政务；万企千校偏育人就业。海外 AIM 是挂牌目录，不是双边运营中台。

## 3. 竞品强项 vs 研企通必须补齐的「成熟度空洞」

### 3.1 科易网：工具密度与高校白标
- 强：推介书/评价/应用图谱等「智成」工具成体系；可按高校做专题平台。
- 研企通差距：缺用户侧门户、缺「一键分析报告」、缺套餐与配额叙事。
- 超越点：不做百个浅工具，先把 **可解释匹配 + 人审触达 + 自助认领** 做成闭环；报告围绕「配对为什么成立」而不是堆报告模板。

### 3.2 转果果：政府背书 + AI 大模型叙事
- 强：五大库、图谱分类、匹配反馈优化、线上线下联动；科技部报道背书。
- 研企通差距：缺公开门户与机构自助、缺反馈学习闭环、缺垂直场景包装。
- 超越点：通用三张卡全国可套；**开源可私有化**；前期不绑单一城市/单一行业。

### 3.3 InnoMatch：需求导向与经纪人市场化
- 强：大企业发需求、全球渠道、技术经理人协作奖励、产业创新中心。
- 研企通差距：缺社区/经纪人分成、缺全球渠道、缺站内沟通产品化。
- 超越点：先做 **运营驱动的冷启动撮合**（爬取→匹配→找人），比等双方自发注册更适合早期；经纪人生态放中后期。

### 3.4 火石：数据与产业智能体
- 强：产业数据资产、招商/科技金融智能体。
- 与研企通：赛道相邻但不重合；可合作不宜正面硬刚「产业大脑」。
- 研企通坚持：成果/能力/需求撮合主线，不扩成政府产业大脑。

### 3.5 产教融合就业类平台
- 强：校企账号多、实习岗位多。
- 弱：几乎不做专利/TRL/转化合同链路。
- 研企通坚持：科研向转化，不做成实习招聘站。

## 4. 成熟产品必须有、且要超越竞品的优先级

1. **双端体验**：高校/企业门户 + 运营中台（现仅有运维台）。
2. **角色与权限**：admin / operator / org_user（现仅 API Key）。
3. **定时双边采集 + 数据质检**：长期任务，不是点一次按钮。
4. **AI 分析报告页**：对组织/需求/匹配出「可读、可导出」的中文报告。
5. **通知中心 + 人审触达**：站内通知 + 邮件草稿闭环。
6. **商业化骨架（可先免费）**：套餐、配额、功能开关；支付可桩。
7. **机构自助**：认领组织、维护三张卡、看推荐、申请对接。
8. **开源私有化与可解释分数**：相对科易/转果果的差异化护城河。

## 5. 研企通定位一句话（对标后校准）

> 做「可私有化、可解释、运营可冷启动」的科研能力/成果与企业需求对接产品：前期自采双边数据自转匹配，中期拉机构上平台自助，后期再叠经纪人生态与白标；不做成产业大脑，也不做成实习就业平台。

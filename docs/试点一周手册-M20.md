# 研企通 · 试点一周手册（M20）

面向：**高校技术转移中心（TTO）或园区经纪人**用当前构建跑 5 天试点。  
边界写清楚：**可以试点验证流程；不可对外宣称「已具备收费级正式交付 / 已接真支付 / 已合规电子签」。**

## 0. 试点前准备（0.5 天）

| 项 | 说明 |
|----|------|
| 环境 | API `:3100` 已起；`npm run gate` 绿 |
| 账号 | 运维 `admin / yanqi123`；再建 1 个 `BROKER`；机构账号各 1（需求方企业 + 供给方实验室） |
| 数据 | 导入或手工建 ≥5 条需求、≥10 条能力/成果；尽量填 TRL、许可、行业标签 |
| 诚实预期 | 邮件可能干跑；支付/DNS/客服未接；文档模板≠律师意见≠电子签 |

## 1. 五日路径

### Day 1 · 建档与标签
1. 运维打开「行业标签」，给重点能力/需求打 `taxonomy`（如 `mfg.vision`）。  
2. 门户机构补全 TRL / 许可 / 最低 TRL。  
3. 跑一次匹配，看解释面板与冲突芯片。  
**反馈收集**：标签好不好找？缺哪些类？

### Day 2 · 经纪人跟进
1. 分派经纪人；看「经纪人产能」看板（逾期/阶段/剧本转化）。  
2. 对 2–3 条线索套「跟进剧本」，干跑发信。  
3. 标记意向/婉拒，看漏斗条是否涨数。  
**反馈**：产能预警阈值是否合理？话术要改哪几句？

### Day 3 · 合同前清单 + 文档草稿
1. 打开对接「合同前清单」，勾关键项。  
2. 试「确认意向」——关键未齐应警告；业务坚持再用强制。  
3. 「合同模板」选 NDA 摘要 / 意向书 / 样品备忘，对匹配生成 `.md` 下载。  
**反馈**：清单项是否够用？模板缺什么字段？（再次强调：非法律意见）

### Day 4 · 专家复核与金标
1. 挑 2 张能力/成果提交「专家复核」→ 分派 → 通过。  
2. 确认卡片出现「同行复核」金标，解释面板可见。  
**反馈**：谁适合当复核人？通过标准口语化怎么写？

### Day 5 · 复盘与案例
1. 关闭 1–2 条对接（成交或流失）。  
2. 「脱敏案例」从匹配生成 → 运营发布 → 门户「脱敏案例」浏览 / 按标签筛。  
3. 半小时复盘会：记下摩擦点（见下表）。  

## 2. 建议回收的反馈（请原样记）

- 匹配 Top3 是否「能讲给人听」  
- 冲突芯片 / 清单警告有没有挡住瞎推进  
- 经纪人一天实际能跟几单、逾期原因  
- 模板下载后是否还要律师重写（预期：要）  
- 哪些 taxonomy 没用上 / 还缺什么  
- 愿不愿下周继续用（是/否 + 一句原因）

## 3. 可试点 / 不可对外收费宣称

| 可以 | 不可以 |
|------|--------|
| 内部试点、流程演练、收集需求 | 宣称已通过等保/已签真合同 |
| 展示匹配、清单、复核、脱敏案例 | 宣称已接微信/支付宝真收款 |
| 下载业务草稿 Markdown | 把模板当正式法律文件或电子签 |
| 干跑邮件与漏斗统计 | 保证外网 SMTP 必达（视环境） |

## 4. 试点结束后

把反馈开给产品方。默认建议：**暂停继续堆功能波次**，先消化试点；有支付/域名凭证或新的明确域需求再开下一波。

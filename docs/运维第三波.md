# 运维第三波说明

## 发信

1. 匹配会生成 `status=draft` 线索。
2. 运维台「线索 / 草稿」点 **审核通过并入队发送**。
3. 未配置 `SMTP_HOST`+`SMTP_FROM`，或 `SMTP_MODE=draft_only`：状态变为 `dry_run`，只打日志。
4. 配置 SMTP 且 `SMTP_MODE=live`：真发，成功 `sent`，失败 `failed`（看 `failReason`）。

## 作战包

```bash
npm run export:pack
npm run export:pack -- --demandId=<id>
npm run export:pack -- --orgId=<id> --top=15
```
